How this works

Simulated data is the primary dataset because PK Hosting production servers are not accessible to this project (no dashboard login, SSH or API access was ever connected). The generator builds realistic diurnal and weekly patterns with noise, then injects labelled anomalies (spikes, level shifts, saturation, leaks, bandwidth surges, dropouts). Every detector uses only past data, so a flag never uses information from after its minute. Event-level scoring counts an event as detected if any flag falls within the event window plus or minus 5 minutes. To run on a real server, use src/collect_real.py (reads /proc and /sys, standard library only) and feed its CSV through the same detectors. Full method notes are in the project README.
